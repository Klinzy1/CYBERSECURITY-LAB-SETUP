Cybersecurity Lab Setup


 Project Overview

This project documents the creation of a virtual cybersecurity
laboratory using VirtualBox and Kali Linux.

The purpose of the lab is to provide an isolated environment
for learning cybersecurity, ethical hacking, penetration testing,
network configuration and security testing

 Objectives

- Install and configure VirtualBox
- Install/import Kali Linux
- Create a NAT Network
- Configure Kali network connectivity
- Test network connectivity
- Document the complete laboratory setup

Tools Used

- Oracle VirtualBox
- Kali Linux
- NAT Network
- Linux Terminal

 Installation

 1. Install VirtualBox

VirtualBox was installed on the host computer.

 2. Install Kali Linux

The official Kali Linux VirtualBox image was imported into VirtualBox.

 3. Create NAT Network

A NAT Network named CyberLab-NAT was created.

 4. Configure Kali

Kali Linux was connected to the CyberLab-NAT network.

 5. Test Connectivity

Network connectivity was tested using ping and IP configuration commands.
